# AEGISSTOR ATLAS — Reality Data Provenance & Stream Invariants

## 1. Provenance Classification
Every telemetry record ingested into AEGISSTOR is stamped with an immutable provenance label:

| Provenance Label | Source Description | Reliability Level |
|:---|:---|:---:|
| `REAL_HARDWARE` | Live telemetry from Linux kernel `/proc/diskstats`, `sysfs`, or Prometheus `node_exporter`. | Highest |
| `CONTROLLED_EXPERIMENT` | Measurements collected from isolated benchmark runs (FIO, SNIA trace harnesses). | High |
| `PUBLIC_BENCHMARK` | Peer-reviewed public storage traces (e.g. Alibaba Cluster Traces, Microsoft SNIA). | Medium |
| `SYNTHETIC_SIMULATION` | Physics-informed deterministic time-series generated by `SyntheticGenerator`. | Informational |

## 2. Stream Sanitization & Integrity Rules
The `TelemetryStreamSanitizer` enforces strict stream hygiene:
1. **Never Silently Zero-Fill**: Missing intervals are identified, quantified, and flagged with start/end timestamps. Missing values are never silently replaced with $0.0$.
2. **Deduplication**: Records are deduplicated by `(timestamp, metric_name)` key tuples.
3. **Out-of-Order Handling**: Chronological sorting is applied immediately upon adapter ingestion.
4. **Unit Normalization**:
   - Capacity metrics converted to bytes or percentage (`%`).
   - Throughput converted to $\text{MB/s}$.
   - Latencies converted to milliseconds ($\text{ms}$).
   - I/O frequencies converted to $\text{IOPS}$.
